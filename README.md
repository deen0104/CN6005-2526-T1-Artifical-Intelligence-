# CN6005-2526-T1-Artifical-Intelligence-


In Week 1, I learned how to use Python’s core data structures, including lists, tuples, dictionaries, and nested lists, which are essential for storing and organising data in AI applications. I practiced creating and modifying lists using indexing, negative indexing, slicing, and built-in methods such as append, insert, remove, and sort, as well as representing multi-dimensional data using nested lists and 2D arrays. I also explored tuples and their immutability compared to lists, and implemented dictionaries to store and retrieve data using key-value pairs. This week gave me a solid foundation in structuring data efficiently, which is critical for later AI and machine learning tasks


In Week 2, I focused on controlling program logic using conditional statements and loops, which are fundamental for decision-making in AI systems. I implemented if, else, and elif statements to handle multiple conditions, including real-world examples such as a leap year detector and a troubleshooting decision tree. I also worked extensively with for loops and the range function to iterate over values, compute cumulative results such as factorials and sums, and generate number sequences and patterns. This week strengthened my ability to translate logical flowcharts and rules into structured Python code, preparing me for more advanced algorithmic and AI-based programming 


In Week 3, I applied machine learning classification techniques using the Titanic dataset to predict passenger survival and evaluate model performance. I implemented both K-Nearest Neighbours (KNN) and Logistic Regression classifiers, including key preprocessing steps such as handling missing values, encoding categorical variables, selecting relevant features, and splitting the dataset into training and testing sets. I trained and tested both models, compared their prediction accuracy, and analysed how different algorithms perform on the same dataset. This week helped me understand the practical differences between distance-based and probabilistic classifiers, as well as the importance of data preprocessing and evaluation when building AI and machine learning models.


In Week 4, I designed and implemented an Artificial Neural Network (ANN) to perform binary classification on a balanced diabetes dataset and compared its performance with Logistic Regression. The workflow included data loading, class balance verification, feature–target separation, train–test splitting, and feature standardisation using a scaler. I built a multi-layer neural network with ReLU activation, L2 regularisation, and dropout to reduce overfitting, and trained the model using binary cross-entropy loss with early stopping. Model performance was evaluated using accuracy, precision, recall, a classification report, and a confusion matrix, achieving an overall accuracy of approximately 76%. This week strengthened my understanding of neural network architecture design, regularisation techniques, and the practical differences between traditional machine learning models and deep learning approaches for classification tasks.

 
In Week 5, I implemented a Convolutional Neural Network (CNN) to classify handwritten digits from the MNIST dataset, which consists of 28×28 grayscale images. The work involved loading and exploring the dataset, visualising sample images, normalising pixel values, and reshaping the data to match CNN input requirements. I designed a deep CNN architecture using multiple convolutional layers, batch normalisation, dropout, and max pooling to improve feature extraction and reduce overfitting, followed by a softmax output layer for multi-class classification. The model was trained and evaluated in Google Colab, achieving a high test accuracy of approximately 99%, and performance was further analysed using predictions and a confusion matrix. This week strengthened my understanding of how CNNs automatically learn spatial features from image data and demonstrated why they significantly outperform traditional models and simple ANNs for image classification tasks.


In Week 6, I applied unsupervised learning techniques using K-Means clustering on a country-level socio-economic dataset to identify patterns based on health expenditure and income. The work involved exploring the dataset, analysing correlations between variables, and selecting relevant features for clustering. Since the optimal number of clusters was not known in advance, I used the Elbow method to determine a suitable value of k, followed by training a K-Means model and assigning cluster labels to each country. I evaluated the clustering quality using the Silhouette score, which showed a strong separation between clusters, and visualised the results using scatter plots with cluster centroids. Finally, I tested the model by predicting cluster membership for new data points. This week strengthened my understanding of unsupervised learning, cluster validation techniques, and how clustering can be used to uncover hidden structures in real-world data.


In Week 7, I studied and applied the Naïve Bayes classifier to multiple categorical datasets to understand probabilistic classification based on Bayes’ theorem. The work involved manually calculating class probabilities and conditional probabilities for different real-world scenarios, including accident prediction, weather-based decision making, loan approval, and disease diagnosis, using structured tables of categorical features (e.g. weather conditions, medical symptoms, employment status). I analysed how assumptions of feature independence affect predictions and explored how changing feature importance or weighting can influence outcomes. In addition, I implemented a Naïve Bayes classifier in Python to reinforce the theoretical concepts through practical application. This week strengthened my understanding of probabilistic reasoning in machine learning and highlighted how Naïve Bayes can be an efficient and interpretable model for classification problems involving categorical data


In Week 8, I explored Decision Tree classifiers by manually analysing a categorical dataset to understand how trees make decisions based on feature splits. I calculated entropy and information gain for each attribute to determine the most informative feature to use as the root node, and then repeated the analysis using Gini impurity to compare how different splitting criteria affect the structure of the tree. Based on these calculations, I manually constructed a decision tree and analysed how different paths lead to classification outcomes. This week strengthened my understanding of how decision trees work internally, the trade-offs between entropy and Gini impurity, and how interpretability is a key advantage of tree-based machine learning models


In Week 9, I explored association rule mining using the Apriori algorithm to discover frequent itemsets and strong relationships within transactional data. I worked with a sample market-basket dataset and applied minimum support and confidence thresholds to identify frequent itemsets, then generated strong association rules and evaluated them using support, confidence, and lift. In addition to manually understanding how Apriori prunes the search space using the downward closure property, I implemented the algorithm in Python by following established tutorials to automate frequent itemset generation and rule extraction. This week improved my understanding of unsupervised pattern mining techniques and demonstrated how association rules can be used to uncover meaningful relationships in large datasets, such as in recommendation systems and retail analytics


In Week 10, I explored Natural Language Processing (NLP) through the implementation of sentiment analysis to classify text as positive, negative, or neutral. I examined the concept of sentiment analysis, its real-world applications such as product reviews and social media monitoring, and the steps involved in building a sentiment analysis pipeline. Using a predefined sentiment lexicon, I analysed multiple complex sentences to identify emotionally weighted words and determine overall sentiment. I then implemented a sentiment analysis model in Python using CountVectorizer for text feature extraction and a Naïve Bayes classifier for prediction, evaluating performance using accuracy, a confusion matrix, and a classification report. This week strengthened my understanding of text preprocessing, feature extraction, and probabilistic classification for analysing unstructured textual data
